# Reflexión

Durante esta práctica aprendí la importancia de analizar la eficiencia de los algoritmos y no únicamente enfocarme en que el programa funcione. Pude observar cómo la recursividad tradicional realiza cálculos repetidos que incrementan considerablemente el tiempo de ejecución.

La implementación de Memoization me permitió comprender cómo una estrategia sencilla de almacenamiento temporal puede mejorar drásticamente el rendimiento de una aplicación. Además, reforcé el uso de Git Flow y la documentación de resultados mediante métricas reales obtenidas con Stopwatch.
