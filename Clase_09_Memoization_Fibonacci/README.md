# Clase 09 - Optimización Algorítmica Avanzada

## Descripción

En esta práctica se implementó el algoritmo de Fibonacci utilizando dos enfoques diferentes:

* Fibonacci recursivo tradicional (Fuerza Bruta).
* Fibonacci optimizado mediante Memoization.

Posteriormente se realizó una comparación de rendimiento utilizando la clase Stopwatch para medir los tiempos de ejecución de cada método.

## Conceptos Aplicados

* Recursividad
* Memoization
* Complejidad Algorítmica
* Benchmarking
* Optimización de código
* Git Flow

## Resultado

Ambos métodos generan el mismo resultado numérico, sin embargo, el método optimizado reduce significativamente el tiempo de ejecución al reutilizar resultados previamente calculados.
