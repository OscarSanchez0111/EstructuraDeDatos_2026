# DataCore Engine v4.0

![Pruebas del proyecto final](https://github.com/OscarSanchez0111/EstructuraDeDatos_2026/actions/workflows/datacore-final-tests.yml/badge.svg?branch=feature/proyecto-final-datacore-v4)

Proyecto final de la materia Estructura de Datos, desarrollado en C# con .NET 10.

DataCore Engine v4.0 es una aplicación de consola que integra estructuras de datos, algoritmos de ordenamiento, almacenamiento dinámico, búsqueda indexada, métricas de rendimiento, pruebas automatizadas y un menú interactivo para administrar registros en memoria.

Oscar Sánchez

## Objetivo general

Desarrollar un sistema modular para almacenar, ordenar, buscar, eliminar y analizar registros mediante estructuras de datos y algoritmos implementados manualmente.

El proyecto fue construido progresivamente en cuatro fases:

1. Modelado inmutable y Selection Sort.
2. QuickSort recursivo y comparación de rendimiento.
3. Almacenamiento dinámico mediante una lista simplemente enlazada.
4. Integración del sistema, búsqueda binaria indexada y Menú Maestro.

La entrega final conserva todos los proyectos anteriores y los integra en una solución única.
